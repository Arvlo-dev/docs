# Navigation

Open **Project tools → Navigation & appearance** to manage the public navigation.

## Structure

Arvlo navigation has three levels: products, sections, and pages. Browser-edited projects can add and rename products and sections, move pages between them, and reorder both sections and pages.

### Nested pages

This has not yet been implemented.

## Page controls

For each page you can:

- Publish or hide it.
- Move it up or down.
- Assign a Lucide or Font Awesome icon and optional icon color.
- Move it to another product or section in browser-edited projects.

Bulk actions can publish, hide, mark reviewed, or move selected pages.

## Repository projects

For GitHub and GitLab sources, folders determine the initial product and section structure. Arvlo lets you reorder and hide synchronized pages, but you manage source filenames and folders in Git.
