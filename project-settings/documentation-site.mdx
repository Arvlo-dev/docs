# Documentation Site

Project owners can open **Project tools → Project settings** to configure the published site.

## Identity and URLs

You can change the project name, description, and public URL slug. In production, the project is available at `https://<slug>.arvlo.page`. Changing a page slug can create a redirect suggestion, which you can review under **Project tools → Redirects**.

## Theme

Arvlo supports a site logo, accent presets or a custom hex color, font presets or a custom font family, left or right sidebar placement, collapsible navigation sections, and a product switcher in the navigation or in a separate top or bottom bar.

Logos may be PNG, JPEG, or WebP and must be no larger than 512 KB.

## Page layout

Browser-edited pages can use narrow, standard, or wide content; left, right, or hidden on-this-page navigation; an optional hero image URL; and optional reading time and word count.

## Footer and not-found page

Project settings include footer text and a footer link, plus the title, description, action label, and action URL used for missing pages.

## Social cards

Arvlo generates Open Graph and Twitter cards from each page's title and description. Choose one design or rotate among available designs, with optional exclusions.

## Custom domain

Enter a hostname such as `docs.example.com`, add the TXT record Arvlo provides, and choose **Verify ownership**. Then add the displayed proxied CNAME record and choose **Finish connection**.
