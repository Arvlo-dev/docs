# AI Answers

When a project owner enables the AI documentation assistant, readers can choose **Ask AI** from the published navigation.

Enter a question about the documented product. Arvlo ranks visible pages for relevance, sends the documentation context and recent conversation to the selected model, and returns an answer with links to relevant source pages.

The assistant is instructed to say when the documentation does not contain an answer. Its response style can change tone and formatting, but it cannot intentionally expand the source set beyond published project documentation.

## Improve answers

Improve the underlying pages when an answer is missing or unclear. Use **Reader insights** to review search gaps and negative feedback, then publish the corrected documentation. Future answers use the latest published content automatically.
