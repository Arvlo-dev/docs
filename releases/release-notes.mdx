# Release Notes

Release notes are plain text entered with a version and title. Published entries appear newest first on the project's public releases page and in its RSS feed.

## Recommended structure

State the reader-visible outcome first, then list important changes, fixes, and any action the reader must take. Keep a release focused on what changed rather than internal implementation detail.

```text
Added
- Search now respects reader-selected versions.

Changed
- The navigation editor supports bulk moves.

Fixed
- Redirects now preserve links after slug changes.
```
