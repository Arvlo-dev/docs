# Creating Releases

1. Open **Project tools → Reader insights**.
2. Select **Releases**.
3. Enter a version and title.
4. Add release notes.
5. Select **Published** to make the release public, or leave it clear to save a draft.
6. Choose **Save release**.

Version values must be unique within a project. Arvlo treats the value as text and does not enforce semantic versioning.

Published releases appear at `/releases` and in the project's release RSS feed. The newest published release is linked from documentation pages.

Use **Edit** to revise a release or switch its published state. Use **Remove** to delete it.
