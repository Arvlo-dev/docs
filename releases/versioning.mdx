# Versioning

Arvlo accepts any unique text value as a release version.

## Semantic version validation and automatic increments

This has not yet been implemented.

Repository pages can declare release and compatibility metadata in frontmatter:

```yaml
---
release: v2.4.0
supportedVersions:
  - v2
  - v1
---
```

The latest published project release contributes to page trust. A page is considered current when its `release` value matches that release. `supportedVersions` can also drive a configured version reader selector.
