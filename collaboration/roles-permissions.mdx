# Roles & Permissions

Arvlo currently has two project roles.

| Capability | Owner | Editor |
| --- | :---: | :---: |
| View and edit pages | Yes | Yes |
| Save drafts and publish | Yes | Yes |
| Organize navigation | Yes | Yes |
| Use reader insights and releases | Yes | Yes |
| Manage project settings and integrations | Yes | No |
| Add or remove collaborators | Yes | No |
| Delete the project | Yes | No |

## Owner

The account that creates a project is its owner.
