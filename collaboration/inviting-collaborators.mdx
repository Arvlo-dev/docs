# Inviting Collaborators

Only the project owner can manage collaborators.

## Add an editor

1. Open the project.
2. Choose **Project tools → Project settings**.
3. Find **Collaborators**.
4. Enter the email address of an existing Arvlo account.
5. Choose **Add editor**.

Arvlo adds the user immediately, so the person must create an Arvlo account before you add them.

## Invitation emails and pending invitations

This has not yet been implemented.

## Remove an editor

In **Collaborators**, choose **Remove** beside the person. Removing access does not delete their prior page revisions.
