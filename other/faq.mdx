# Frequently Asked Questions

## Can I start without a repository?

Yes. Choose a starter template or import up to 100 Markdown or MDX files into a browser-edited project.

## Can I edit synchronized Git pages in Arvlo?

No. GitHub and GitLab pages are read-only in the Arvlo editor. Change them in the repository and refresh the project.

## Are drafts public?

No. A draft-only page stays private until it is published. Editing an already-published browser page creates a separate draft while the current version remains live.

## Can documentation be private?

This has not yet been implemented.

## What roles are available?

Projects have one owner and any number of editors.

### Additional admin and viewer roles

This has not yet been implemented.

## Does Arvlo support custom domains?

Yes. Owners verify hostname ownership with a TXT record, then connect traffic with the CNAME settings shown in the dashboard.

## How does the AI assistant choose answers?

It receives visible published pages, ranks them against the question, and is instructed to answer only from that documentation.
