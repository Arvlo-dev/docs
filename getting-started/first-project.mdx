# Create Your First Project

From the dashboard, choose **New project**. The setup wizard asks how you want to start, collects the source details, and shows a final site preview before creation.

## Choose a source

### Starter template

Create a browser-edited project from a blank, API reference, library, or product-guide template. Template pages begin as private drafts.

### Import files

Import up to 100 `.md` or `.mdx` files. The combined upload must be smaller than 2 MB. Arvlo uses frontmatter titles when present, derives missing titles from filenames, and maps folders into products and sections.

### GitHub

Enter an owner, repository, branch, and optional docs folder. Connect a GitHub account for private repository access and automatic webhook setup.

### GitLab

Enter a GitLab URL, project path, branch, and optional docs folder. Private projects require an access token with `read_repository`. You can also enter the secret for a manually configured GitLab webhook.

## Project details

Every project requires a name and a unique public URL slug. The description is optional but recommended because it appears in project and publishing metadata.

Published pages are public; unfinished browser pages remain private as drafts or can be hidden from navigation.

### Project visibility controls

This has not yet been implemented.

## Publish the first page

After creation, select a page in the project sidebar. For a browser-edited project, replace the starter text, check the rendered preview, and choose **Publish**. For a repository project, choose **Refresh from Git** if the initial synchronization has not populated pages yet.

Use **View published site** to verify the result.
