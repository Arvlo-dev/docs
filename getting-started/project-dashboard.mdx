# Project Dashboard

The project dashboard combines page editing, navigation, settings, and reader-improvement workflows.

## Page sidebar

The left sidebar lists pages by product and section. Select a page to edit it. Browser-edited projects also show a **+** button for creating a page; repository projects show synchronized files.

## Editor

Browser-edited pages have fields for title, slug, description, product, section, content width, on-this-page navigation, hero image, and reading metadata. The MDX editor and rendered preview update together.

Use **Save draft** to keep private changes, **Discard draft** to return to the published version, and **Publish** to make the editor state live. Repository projects show a rendered preview and source path instead of editable fields.

## Project tools

The menu contains:

- **Reader insights** for feedback, searches, journeys, releases, answers, verification, CI, and suggestions.
- **Documentation health** for project and page quality checks.
- **Navigation & appearance** for products, sections, order, icons, and visibility.
- **Redirects** for preserving moved URLs.
- **Revision history** for browser-edited pages.
- **Reusable snippets** for shared MDX.
- **Import OpenAPI** for browser-edited API drafts.
- **Project settings** for owners.
- **Refresh from Git** for repository projects.

## Published site

Choose **View published site** at the bottom of the sidebar. The dashboard also calculates page trust from recent review, verified examples, open reader signals, CI status, and current-release coverage.
