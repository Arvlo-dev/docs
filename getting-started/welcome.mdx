# Welcome

Arvlo is a documentation platform for writing, publishing, and improving product documentation. You can author in the browser, import existing Markdown or MDX, or synchronize a GitHub or GitLab repository.

## What Arvlo provides

- A rendered MDX editor with private drafts and page revisions.
- Published sites with search, responsive navigation, page feedback, suggestions, and generated social cards.
- Products and sections for organizing multiple documentation sets.
- GitHub and GitLab synchronization.
- Documentation health, review reminders, answer gaps, and reader insights.
- Releases, reader journeys, reusable support answers, snippets, and OpenAPI imports.
- Optional Slack, Discord, outbound webhook, and docs-grounded AI integrations.

## Core concepts

### Projects

A project contains pages, navigation, appearance, releases, reader activity, collaborators, and integrations. A project uses one source: the browser editor, GitHub, or GitLab.

### Products and sections

Products are top-level documentation sets. Each product contains sections, and each section contains pages. This same structure becomes the published navigation.

### Drafts and published pages

Browser-edited pages can have a private draft while their last published version remains live. A new draft-only page is hidden until its first publish. Repository projects are edited in Git and synchronized into Arvlo.

### Reader signals

Published sites collect anonymous page views, searches, helpful or unhelpful feedback, suggestions, journey activity, and support-answer views. Arvlo turns these signals into an improvement queue.
