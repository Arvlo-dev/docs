# Project Insights

Open a project and choose **Project tools → Reader insights**. The overview shows totals for page views, searches, helpful responses, and unhelpful responses.

## Answer gaps

Arvlo turns unsuccessful searches and negative page feedback into answer gaps. Each gap includes its evidence, number of signals, related page when available, and one of three statuses: **open**, **planned**, or **resolved**.

Use the status menu to keep the improvement queue current. Written feedback is retained with the related gap so you can read the original comments.

## Documentation health

Choose **Project tools → Documentation health** for an overall score and page-level checks. Arvlo checks for stale reviews, thin content, broken internal links, reader gaps, verified examples, CI status, and current-release coverage.

The selected page also receives completion guidance for its title, description, headings, working example, reader feedback, and related-page link.

## Reader activity

Published documentation records anonymous page views, exits, searches, feedback, journey steps, and support-answer views. Arvlo groups repeated feedback from the same browser session so the dashboard does not inflate totals.

Analytics are project-wide and do not provide named visitor profiles.
