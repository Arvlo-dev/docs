# User Journeys

Journeys connect several documentation pages into an ordered path, such as onboarding, migration, or deployment.

## Create a journey

1. Open **Project tools → Reader insights**.
2. Select **Journeys**.
3. Enter a name and optional description.
4. Select at least one page in the order it should appear.
5. Enable **Published** when the journey is ready for readers.
6. Choose **Create journey**.

Published journeys appear on every included page. Draft journeys remain in the dashboard.

## Maintain a journey

Use **Edit** to change its name, description, pages, or published state. Use **Remove** to delete it. Journey-step activity is included in project analytics.
