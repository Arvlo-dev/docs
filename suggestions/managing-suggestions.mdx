# Managing Suggestions

Open **Project tools → Reader insights → Suggestions**. The tab displays all reader suggestions and shows the number still open.

Set each suggestion to:

- **open** while it still needs review;
- **accepted** when you agree with and have handled it;
- **declined** when you will not make the requested change.

Accepting a suggestion does not automatically edit or publish the page. Make the requested change in the editor or source repository, then update the suggestion's status.
