# Webhooks

Project owners can configure outbound webhooks in **Project tools → Project settings → Outbound webhooks**.

1. Enable outbound webhooks.
2. Enter an HTTPS destination URL.
3. Enter a long random signing secret.
4. Select at least one event.
5. Save project settings.

Supported events are `health`, `answer-gap`, `suggestion`, `unhelpful`, and `sync.completed`.

## Verify a delivery

Arvlo sends JSON and signs the raw request body with HMAC-SHA256. Compare your computed digest with the `x-arvlo-signature-256` header before processing the event.

```js
import { createHmac, timingSafeEqual } from "node:crypto";

const expected = createHmac("sha256", process.env.ARVLO_WEBHOOK_SECRET)
  .update(rawBody)
  .digest("hex");

const valid = timingSafeEqual(
  Buffer.from(signature, "hex"),
  Buffer.from(expected, "hex"),
);
```
